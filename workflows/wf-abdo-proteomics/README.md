# Proteomics Data Processing Workflow

This workflow is designed for proteomics data processing, including data ingestion, feature engineering, standardization, segmentation, statistics, advanced analysis, transformation, and visualization.

## Workflow Steps

1.  **Data Ingestion** (`01-data-ingestion`): Load and prepare the initial dataset.
2.  **Feature Engineering** (`02-feature-engineering`): Clean and translate data features.
3.  **Standardization** (`03-standardization`): Standardize the data.
4.  **Segmentation** (`04-segmentation`): Segment the data for analysis.
5.  **Statistics** (`05-statistics`): Perform comprehensive statistical analysis.
6.  **Advanced Analysis** (`06-advanced-analysis`): Run machine learning and PCA.
7.  **Transform** (`07-transform`): Melt and transform data structures.
8.  **Visualization Dashboard** (`08-visualization-dashboard`): Create a dashboard to visualize results.

## Usage

Each step contains a `run.sh` script to execute the corresponding task.
Global parameters are defined in `global_params.json`.
