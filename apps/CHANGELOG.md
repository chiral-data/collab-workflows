# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [2026-02-13]

### Added

- boltzgen_2026_02_13: Added BoltzGen application for AI-based protein/peptide binder design (nvidia/cuda:12.1.1, boltzgen)
- boltz_report_2026_02_13: Added Boltz report generator for Boltz-2 and BoltzGen dashboards (Python 3.8, pandas, plotly, numpy)

## [2026-01-17]

### Added

- qsar_20260107_v1: Added QSAR workflow environment (RDKit, TensorFlow, Scikit-learn) for quantitative structure-activity relationship modeling

## [2025-12-08]

### Added

- pocketeer_2025_12_08: Added pocketeer application for protein pocket detection (pocketeer v0.1.0, PyMOL, imageio)
